# SonnaKanji

Kanji mnemonics for the JLPT: a static, SEO-friendly Astro site with one page per
kanji, swipeable cards and browser-based spaced repetition (FSRS). N5 and N4 are
hand-tuned. N3, N2 and N1 are in beta: their mnemonics are first drafts and their
drawings are generated by `scripts/art/auto-scenes.mjs`.
There is no database. Review progress lives in the visitor's `localStorage`.

```bash
npm install
npm run dev     # http://localhost:4321
npm test        # SRS logic
npm run build   # static site in dist/, deploy to any static host
```

Pushing to `main` deploys to Vercel. Canonical URLs and the sitemap use Vercel's
production domain automatically; set `SITE_URL` in Vercel to override it.

## Content

| File | Written by | Purpose |
| --- | --- | --- |
| `src/data/kanji.json`, `public/glyphs/` | `npm run data` | Generated from the sources below |
| `src/data/mnemonics.json` | Hand | One sentence per kanji |
| `src/data/meanings.json` | Hand | Replaces noisy KANJIDIC headline meanings |
| `src/data/parts.json` | Hand | English names for kanji components |
| `src/data/slugs.json` | `node scripts/build-slugs.mjs` | Permanent URL per kanji; existing entries never change |
| `scripts/art/scenes.mjs` | Hand | One drawing per kanji, built from the kit in `sprites.mjs` |
| `art-source/hand/` | Hand | Transparent N5 and N4 illustration sources; these take priority over scenes |
| `art-source/n5-shape-briefs.json`, `art-source/n4-shape-briefs.json` | Hand | Visual memory cues and component layouts for the 79 N5 and 166 N4 illustrations |
| `art-source/review/` | Hand | Contact sheets for reviewing the N5 and N4 sets |
| `public/art/` | `npm run art` | WebP files from hand sources and SVGs from scenes; rerun after editing either |

`npm run data` caches every response in `.cache/`, so reruns are offline and
never touch the hand-written files. To finish a beta level, move its scenes into
`scenes.mjs`, review its mnemonics, then set `beta: false` in `src/lib/kanji.ts`.
